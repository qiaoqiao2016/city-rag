## 3. 基础设施部署

### 3.1 Docker 容器部署（开发/测试环境）

所有中间件通过 Docker Compose 一键启动：

```bash
# 进入后端目录
cd backend

# 启动所有基础设施服务
docker-compose up -d

# 验证所有服务状态
docker-compose ps

# 预期输出（全部 Up）：
#   Name                    Status
#   city-rag-postgres       Up (healthy)
#   city-rag-redis          Up
#   city-rag-influxdb       Up
#   city-rag-emqx           Up
#   city-rag-kafka          Up
```

### 3.2 服务端口

| 服务 | 端口 | 说明 |
|------|------|------|
| PostgreSQL | 5432 | 主数据库 |
| Redis | 6379 | 缓存 |
| InfluxDB | 8086 | 时序数据库，UI: http://localhost:8086 |
| EMQX | 1883 / 18083 | MQTT / 管理面板 |
| Kafka | 9092 | 消息队列 |
| 后端 API | 8080 | Spring Boot |
| 前端 | 3000 | Vite 开发服务器 |

### 3.3 Kafka Topic 初始化

```bash
# 进入 Kafka 容器创建所需 Topic
docker exec city-rag-kafka kafka-topics.sh --create \
  --topic telemetry-raw          --partitions 3 --replication-factor 1 --bootstrap-server localhost:9092

docker exec city-rag-kafka kafka-topics.sh --create \
  --topic alert-event            --partitions 3 --replication-factor 1 --bootstrap-server localhost:9092

docker exec city-rag-kafka kafka-topics.sh --create \
  --topic data-update            --partitions 1 --replication-factor 1 --bootstrap-server localhost:9092

# 验证 Topic 列表
docker exec city-rag-kafka kafka-topics.sh --list --bootstrap-server localhost:9092
```

### 3.4 数据库初始化

PostGIS 容器启动时会自动执行 `init-db.sql`。手动初始化：

```bash
# 手动执行初始化脚本（如容器重启后需要重新初始化）
docker exec -i city-rag-postgres psql -U cityrag -d city_rag < backend/init-db.sql

# 验证建表
docker exec city-rag-postgres psql -U cityrag -d city_rag -c "\dt"

# 预期输出表：
#   alert_events, alert_rules, buildings, cameras, data_conflicts,
#   ecology_stations, enterprises, fire_hydrants, grids,
#   households, manhole_covers, police_stations, populations,
#   roads, street_lights, audit_logs
```

## 4. 后端部署

### 4.1 构建

```bash
# 确保 Java 17 和 Maven 3.9+ 已安装
java -version   # 需 >= 17
mvn -version    # 需 >= 3.9

cd backend

# 全量构建（跳过测试）
mvn clean package -DskipTests -T 4

# 构建产物：
# city-rag-gateway/target/city-rag-gateway-1.0.0.jar  ← 可执行 JAR
```

### 4.2 运行

```bash
# 开发环境运行
java -jar city-rag-gateway/target/city-rag-gateway-1.0.0.jar \
  --spring.profiles.active=dev

# 生产环境运行（使用外部配置文件）
java -jar city-rag-gateway/target/city-rag-gateway-1.0.0.jar \
  --spring.profiles.active=prod \
  --spring.config.location=file:/etc/city-rag/application-prod.yml

# 后台运行（生产环境）
nohup java -jar city-rag-gateway/target/city-rag-gateway-1.0.0.jar \
  --spring.profiles.active=prod \
  > /var/log/city-rag/app.log 2>&1 &
```

### 4.3 生产环境配置模板

创建 `/etc/city-rag/application-prod.yml`：

```yaml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:postgresql://postgres-cluster:5432/city_rag
    username: cityrag_prod
    password: ${DB_PASSWORD}           # 从环境变量读取
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
  redis:
    host: redis-cluster
    port: 6379
    password: ${REDIS_PASSWORD}
  kafka:
    bootstrap-servers: kafka-cluster:9092

city-rag:
  cors:
    allowed-origins: https://city-rag.example.com,https://display.city-rag.example.com

logging:
  file:
    path: /var/log/city-rag
```

### 4.4 Systemd 服务配置

创建 `/etc/systemd/system/city-rag.service`：

```ini
[Unit]
Description=城市资源一张图 API 服务
After=network.target postgresql.service redis.service kafka.service

[Service]
Type=simple
User=cityrag
Group=cityrag
Environment=DB_PASSWORD=xxx
Environment=REDIS_PASSWORD=xxx
ExecStart=/usr/bin/java -jar /opt/city-rag/city-rag-gateway-1.0.0.jar --spring.profiles.active=prod
SuccessExitStatus=143
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启用服务
sudo systemctl daemon-reload
sudo systemctl enable city-rag
sudo systemctl start city-rag
sudo systemctl status city-rag
```

## 5. 前端部署

### 5.1 构建

```bash
cd frontend

# 安装依赖
npm install

# 配置环境变量（复制并编辑）
cp .env.example .env
# 编辑 .env，填入 Cesium Ion Token 和天地图 Token

# 生产构建
npm run build

# 构建产物：
# frontend/dist/  ← 静态文件目录
```

### 5.2 Nginx 配置

创建 `/etc/nginx/conf.d/city-rag.conf`：

```nginx
# 前端静态资源
server {
    listen 80;
    server_name city-rag.example.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name city-rag.example.com;

    ssl_certificate     /etc/nginx/ssl/city-rag.pem;
    ssl_certificate_key /etc/nginx/ssl/city-rag.key;

    # 前端静态资源
    root /opt/city-rag-frontend/dist;
    index index.html;

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml image/svg+xml;

    # 缓存策略
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # SPA 路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 30s;
    }

    # WebSocket 代理
    location /ws/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 3600s;
    }

    # API 文档
    location /swagger-ui/ {
        proxy_pass http://127.0.0.1:8080;
    }
    location /v3/api-docs/ {
        proxy_pass http://127.0.0.1:8080;
    }
}
```

### 5.3 大屏端子域名配置

```nginx
server {
    listen 443 ssl http2;
    server_name display.city-rag.example.com;

    root /opt/city-rag-frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 大屏端 API（更高频的数据刷新）
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_read_timeout 5s;
    }
}
```

## 8. 常见问题

### 8.1 Docker 服务启动失败

```bash
# 查看具体容器日志
docker logs city-rag-postgres --tail 50

# PostGIS 常见问题：端口冲突
# 修改 docker-compose.yml 中 ports 映射

# Kafka 常见问题：容器退出
# 检查内存是否充足，Kafka 需要至少 2GB 堆内存
```

### 8.2 数据库连接失败

```bash
# 验证数据库运行
docker exec city-rag-postgres pg_isready -U cityrag

# 验证应用配置
# 检查 application.yml 中 datasource.url 的主机名和端口

# 权限问题
docker exec -it city-rag-postgres psql -U cityrag -d city_rag
# ALTER USER cityrag WITH PASSWORD 'new_password';
```

### 8.3 前端页面空白

```bash
# 1. 检查浏览器控制台是否有 401/404 错误
# 2. 验证 Cesium Ion Token 是否配置
# 3. 验证 Nginx 代理配置是否正确
# 4. 检查 API 地址是否可访问
curl -s http://localhost:8080/api/v1/buildings?page=1&size=1
```

### 8.4 Kafka 消费滞后

```bash
# 查看消费者组 Lag
docker exec city-rag-kafka kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 \
  --group city-rag-group \
  --describe

# 如果 Lag 持续增长，检查：
# 1. 告警引擎是否正常运行
# 2. 数据库写入是否成为瓶颈
# 3. 是否需增加分区数
```

## 9. 回滚方案

### 9.1 后端回滚

```bash
# 保留上一版本 JAR
cp city-rag-gateway-1.0.0.jar city-rag-gateway-1.0.0.jar.bak

# 回滚时替换并重启
cp city-rag-gateway-0.9.0.jar city-rag-gateway-1.0.0.jar
sudo systemctl restart city-rag
```

### 9.2 数据库回滚

```bash
# 使用 pg_dump 备份文件恢复
psql -U cityrag -d city_rag < backup_20260521.sql

# 或使用 Wal-G 时间点恢复
wal-g time-targeted-restore --target "2026-05-20T00:00:00Z"
```

### 9.3 前端回滚

```bash
# Nginx 指向上一版本目录
rm -f /opt/city-rag-frontend/current
ln -s /opt/city-rag-frontend/releases/v0.9.0 /opt/city-rag-frontend/current
sudo nginx -s reload
```
