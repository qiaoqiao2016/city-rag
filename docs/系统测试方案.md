> 版本：v1.1
> 日期：2026-05-21

## 1. 测试分层策略

| 层级 | 技术栈 | 速度 | 覆盖目标 |
|------|--------|------|---------|
| 单元测试 | JUnit 5 / Vitest | < 10ms/用例 | DTO、工具类、Store 状态逻辑 |
| 服务层测试 | Mockito + JUnit 5 | < 100ms/用例 | 告警规则评估、空间距离、业务 CRUD |
| 集成测试 | MockMvc + H2 | < 1s/用例 | API 端点 HTTP 请求/响应、SQL 映射 |
| E2E 测试 | Playwright | < 10s/场景 | 用户操作流（二期引入） |

### 测试数据准备

- 单元测试：@BeforeEach 创建 mock 实体，无需数据库
- Service 层测试：Mockito @Mock 注入 Mapper，@InjectMocks 注入 Service
- Controller 层测试：@WebMvcTest + @MockBean 模拟 Service
- DAO 集成测试：@SpringBootTest + @Sql 注入 H2，事务自动回滚

## 3. 运行方式

```bash
# 后端全部测试
cd backend && mvn test

# 先编译再运行指定模块
mvn install -DskipTests
mvn test -Dtest=ThresholdRuleEvaluatorTest -pl city-rag-service

# 前端测试
cd frontend && npm install && npm run test
```

## 5. 边界场景说明

| 类别 | 覆盖场景 | 对应测试 |
|------|---------|---------|
| 空值 | telemetryData=null | ThresholdEvaluatorTest |
| 空值 | conditions=null / channels=null | EntityTest, NotificationDispatcher |
| 不存在 | ID 不存在 | BuildingServiceTest, BuildingMapperTest |
| 超限 | 阈值触发 | ThresholdEvaluatorTest |
| 未超限 | 阈值未触发 | ThresholdEvaluatorTest |
| 重复 | 同规则重复触发 | AlertRuleEngineTest |
| 非法 | page=-1 / 路径缺失 | BuildingControllerNegativeTest |
| 未知 | 未知通道 email | NotificationDispatcherTest |
| 精度 | 浮点数距离 | SpatialQueryServiceTest |
